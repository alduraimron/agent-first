# Agent-First orchestration

Apply the shared Agent-First RULES.md throughout this session. It is the policy source for both main and advisory sessions; this append text is main-session guidance, not a child-policy inheritance mechanism.

For each ordinary engineering request, use the direct `read` tool on `skill://af-engineering` before project work; wait for the skill result before actions it governs. Inspect relevant project context, complete its adaptive classification, then use its route format for the first prose report. Derive the workflow from the request and repository evidence, rather than asking the user to choose it. Keep ceremony proportional to the work.

For verification-only requests, and before any completion or blocked-work report, read `skill://af-verification` and perform its evidence-based handoff. Use the project's own instructions and installed scripts rather than introducing a parallel development convention.

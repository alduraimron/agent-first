# Browser and accessibility verification

1. Read `xd://eval/browser` before first use. Start only a task-owned local runtime with authorized fixture data or an explicitly authorized target. Record launch command/cwd, actual URL and readiness evidence. Browser eval requires the normal native approval; headless approval failure is NOT-RUN, not permission to enable eval globally.
2. Open an owned named tab using explicit `app: 'tern'`. Inspect the actual open result/backend. Native inability to host Tern can cause a fallback even with a requested app: if the result is not Tern, close the owned fallback tab and record NOT-RUN rather than accepting/installing/switching silently.
3. Observe before interaction; use real controls, labels, keyboard and browser helpers. Exercise the acceptance path and relevant empty/error/validation cases. Wait for actual resulting text/state, not a fixed sleep. Scripts may inspect DOM/state; do not alter page state to manufacture success.
4. Inspect semantic labels/roles, keyboard reachability/activation, focus after actions/errors, status/error announcements, and relevant layout/contrast/responsive behavior. Use installed accessibility tools if already authorized; do not fetch axe/Playwright/browser binaries. Record unsupported/manual screen-reader, contrast, zoom, viewport or cross-browser checks as gaps rather than asserting full accessibility compliance.
5. Inspect resulting page and relevant page errors/console/network evidence the Tern backend supports; retain screenshot and observed viewport. Screenshots prove appearance only, not keyboard behavior or backend correctness. Exercise actual API/data persistence separately when the flow depends on it.
6. Capture actual inputs/actions, expected versus observed state, evidence paths and limitations. Close only this task's owned tabs and services, retaining useful artifacts first. Classify browser coverage PASS only for the exercised flow; required but unavailable checks remain NOT-RUN. A non-UI task may mark browser NOT-APPLICABLE with its reason.
